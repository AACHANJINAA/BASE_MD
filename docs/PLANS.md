# Plans

이 문서는 현재 개발 계획과 작업 상태를 관리하는 문서입니다.

## 문서 역할

- 지금 진행 중인 기능, 다음 작업, 보류 작업을 정리합니다.
- `GDD/Implemention_Plan.md`의 큰 구현 계획을 실제 작업 단위로 나눠 추적합니다.
- 각 작업의 상태를 `대기`, `진행중`, `완료`, `보류` 등으로 관리합니다.
- 작업 완료 후 커밋으로 남길 범위와 `docs/DECISIONS.md`에 남길 결정을 구분하는 기준으로 사용합니다.

## 작성 예정 항목

- 현재 마일스톤
- 진행 중 작업
- 다음 작업
- 보류 작업
- 최근 작업 메모
