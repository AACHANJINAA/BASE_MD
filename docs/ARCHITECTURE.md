# Architecture

이 문서는 프로젝트의 구조와 책임 범위를 정리하는 기준 문서입니다.

## 문서 역할

- 폴더, 코드 모듈, 씬, 셰이더, 에셋의 배치 기준을 기록합니다.
- 시스템별 책임 범위를 정리해 파일이 어디에 있어야 하는지 판단합니다.
- 렌더링 흐름과 리소스 소유권처럼 코드만 봐서는 파악하기 어려운 구조를 정리합니다.
- 새 폴더나 주요 파일이 추가될 때 구조 변경 이유를 남깁니다.
- 구현 중 구조 판단이 필요하면 `docs/WORKFLOW.md`의 진행 규칙과 함께 확인합니다.

## 작성 예정 항목

- 프로젝트 폴더 구조
- 엔진/프레임워크와 그래픽스 API
- 코드 모듈 책임
- 렌더링 파이프라인 (패스 순서, 렌더 타깃, 후처리)
- 셰이더 구성과 공유 코드
- 리소스/메모리 관리 (버퍼, 텍스처, 로딩·해제)
- 에셋 폴더 책임과 임포트·변환 과정
- 씬/맵 구성
- 데이터 관리 위치
- 빌드 구성과 플랫폼별 차이
- 서드파티 라이브러리
- 구조 변경 기록
