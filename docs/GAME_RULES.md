# Game Rules

이 문서는 실제 게임 플레이 규칙과 밸런스 기준을 정리하는 문서입니다.

## 문서 역할

- 조작, 점수, 승패, 턴, 충돌, 자원, 상태 전환 같은 규칙을 기록합니다.
- 기획 의도보다 실제 플레이 판정 기준을 중심으로 정리합니다.
- 규칙 변경이 생기면 구현과 검증 기준도 함께 확인할 수 있도록 관리합니다.
- 구현 중 규칙이 애매하면 `GDD/Game_GDD.md`와 `docs/WORKFLOW.md`를 함께 참고합니다.

## 작성 예정 항목

- 조작 규칙
- 승리/패배 조건
- 점수와 보상
- 턴/라운드 진행
- 플레이어 상태
- 적/오브젝트 판정
- 예외 상황 처리
