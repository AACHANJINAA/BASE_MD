# Verify

이 문서는 구현 후 확인해야 할 검증 항목을 정리하는 문서입니다.

## 문서 역할

- 기능 구현 후 어떤 방식으로 정상 동작을 확인할지 기록합니다.
- 플레이 테스트, 에디터 확인, 빌드 확인, 자동 테스트 등 검증 방법을 관리합니다.
- 완료 기준을 명확히 해 `docs/PLANS.md`의 상태 관리와 커밋 전 확인을 돕습니다.
- 검증 중 발견한 문제는 `docs/PLANS.md`에 후속 작업으로 남깁니다.

## 작성 예정 항목

- 기능별 확인 항목
- 플레이 테스트 체크리스트
- 빌드 확인 항목
- 회귀 확인 항목
- 알려진 문제
- 완료 기준
