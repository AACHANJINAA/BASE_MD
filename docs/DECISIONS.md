# Decisions

이 문서는 반복해서 확인할 필요가 있는 확정 결정을 짧게 기록하는 문서입니다.

## 문서 역할

- 긴 기획 문서나 커밋 이력을 다시 훑지 않도록 핵심 결정만 보관합니다.
- 게임 방향, 기술 선택, 구조 선택, 운영 규칙처럼 되돌아볼 일이 많은 내용을 기록합니다.
- 결정 이유를 한두 줄로 남겨 이후 작업에서 같은 논의를 반복하지 않게 합니다.
- 임시 아이디어나 미확정 논의는 기록하지 않습니다.
- 완료 이력 전체를 기록하지 않고, 이후 작업 방향에 영향을 주는 결정만 기록합니다.

## 작성 형식

- `[YYYY-MM-DD] 결정 제목`
  - 결정: 확정된 내용
  - 이유: 결정한 이유
  - 영향: 관련 문서, 시스템, 작업 범위

## Decisions

- `[YYYY-MM-DD] 예시`
  - 결정: 새 작업은 먼저 `docs/PLAY_REQUEST.md`로 정리한다.
  - 이유: AI가 모든 문서를 자동으로 읽지 않게 하여 토큰 사용을 줄이기 위해서다.
  - 영향: `docs/WORKFLOW.md`, `docs/AI_USAGE.md`
