# Play Request

AI에게 작업을 요청할 때 사용하는 사용자 개입형 요청서입니다.

필요한 항목만 채워도 됩니다. 비어 있는 항목은 AI가 추정하지 않고, 필요할 때 사용자에게 확인합니다.

## 작업 유형

- 기획
- 구현 계획
- 코드 구현
- 버그 수정
- 구조 변경
- 게임 규칙 변경
- 검증
- 결정 기록

## 작업 대상

예: 플레이어 이동, 보스 전투, 아이템 시스템, UI, 스테이지, 세이브 시스템

## 요청 내용

무엇을 만들거나 수정해야 하는지 적습니다.

## 참조할 문서

예: `docs/GAME_RULES.md`만 확인

## 수정 허용 문서

예: `GDD/Implemention_Plan.md`, `docs/PLANS.md`

## 건드리지 말 문서

예: `GDD/Game_GDD.md`는 수정하지 말 것

## 원하는 결과

예: 구현 계획만 작성 / 코드 수정까지 진행 / 검증 항목만 정리 / 문서 초안만 작성

## 사용자 확인이 필요한 조건

예: 새 파일 만들기 전 확인 / 여러 문서 수정 전 확인 / 구조 변경 전 확인

## 완료 기준

작업이 끝났다고 판단할 수 있는 기준을 적습니다.

## 메모

추가로 AI가 알아야 할 제한, 취향, 우선순위, 참고 사항을 적습니다.
