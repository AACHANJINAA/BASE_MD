# Spec

이 문서는 프로젝트의 동작 사양과 기술 기준을 정리하는 문서입니다.

게임이라면 플레이 규칙과 밸런스를, 그래픽스 프로젝트라면 렌더링 기준과 기술 제약을 중심으로 작성합니다. 해당하지 않는 항목은 비워 두거나 지웁니다.

## 문서 역할

- 기획 의도보다 실제 동작과 판정 기준을 중심으로 정리합니다.
- 구현자가 매번 다시 정하지 않도록 단위, 좌표계, 포맷 같은 공통 기준을 고정합니다.
- 사양이 바뀌면 구현과 검증 기준도 함께 확인할 수 있도록 관리합니다.
- 구현 중 사양이 애매하면 `design/PROJECT_BRIEF.md`와 `docs/WORKFLOW.md`를 함께 참고합니다.

## 작성 방법

- 기획 단계에서 엔진/프레임워크가 정해지면 `공통 기술 기준`의 `값` 칸부터 채웁니다.
- `참고` 칸은 자주 쓰는 엔진의 기본값입니다. 프로젝트에 맞게 확정한 뒤 `값` 칸에 적습니다.
- 엔진 기본값을 그대로 쓰더라도 명시해 둡니다. AI와 구현자가 단위나 축을 추정하지 않게 하기 위해서입니다.

## 게임·시뮬레이션 규칙

해당 프로젝트에 맞는 항목만 남깁니다.

- 조작 규칙 (입력 장치, 키 매핑)
- 승리/패배 또는 완료 조건
- 점수, 평가, 보상
- 턴/라운드/시나리오 진행
- 플레이어 상태 (체력, 게이지 등)
- 오브젝트 상태와 상태 전이
- 판정 기준 (충돌, 범위, 확률)
- 밸런스·튜닝 수치 (값과 조정 가능 여부)

## 렌더링 사양

- 지원 기법과 품질 단계
- 라이팅·셰이딩 모델
- 해상도와 렌더 스케일
- 후처리 구성
- 카메라와 입력 조작
- 디버그 표시 (디버그 드로우, 오버레이, 콘솔 명령)

## 예외 상황 처리

- 지원하지 않는 기능·하드웨어 대응
- 오류 및 폴백 동작
- 잘못된 입력·데이터 처리
