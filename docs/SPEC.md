# Spec

이 문서는 프로젝트의 동작 사양과 기술 기준을 정리하는 문서입니다.

게임이라면 플레이 규칙과 밸런스를, 그래픽스 프로젝트라면 렌더링 기준과 기술 제약을 중심으로 작성합니다. 해당하지 않는 항목은 비워 둡니다.

## 문서 역할

- 기획 의도보다 실제 동작과 판정 기준을 중심으로 정리합니다.
- 구현자가 매번 다시 정하지 않도록 단위, 좌표계, 포맷 같은 공통 기준을 고정합니다.
- 사양이 바뀌면 구현과 검증 기준도 함께 확인할 수 있도록 관리합니다.
- 구현 중 사양이 애매하면 `design/PROJECT_BRIEF.md`와 `docs/WORKFLOW.md`를 함께 참고합니다.

## 작성 예정 항목

### 공통 기술 기준

- 단위와 스케일 (예: 1 unit = 1m)
- 좌표계와 손잡이 방향 (오른손/왼손, Y-up/Z-up)
- 행렬 규칙 (행/열 우선, 곱셈 순서)
- 색 공간과 감마 (sRGB/Linear, HDR, 톤 매핑)
- 텍스처·메시 포맷과 압축 기준
- 대상 플랫폼과 최소 사양
- 성능 예산 (목표 FPS, 프레임 타임, 드로우 콜, 메모리)

### 게임 규칙 (게임 프로젝트)

- 조작 규칙
- 승리/패배 조건
- 점수와 보상
- 턴/라운드 진행
- 플레이어 상태
- 적/오브젝트 판정
- 밸런스 수치

### 렌더링 사양 (그래픽스 프로젝트)

- 지원 기법과 품질 단계
- 라이팅·셰이딩 모델
- 해상도와 렌더 스케일
- 입력·카메라 조작

### 예외 상황 처리

- 지원하지 않는 기능·하드웨어 대응
- 오류 및 폴백 동작
