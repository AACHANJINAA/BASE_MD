# Verify

이 문서는 구현 후 확인해야 할 검증 항목을 정리하는 문서입니다.

## 문서 역할

- 기능 구현 후 어떤 방식으로 정상 동작을 확인할지 기록합니다.
- 플레이 테스트, 에디터 확인, 빌드 확인, 시각 검증, 성능 측정, 자동 테스트 등 검증 방법을 관리합니다.
- 완료 기준을 명확히 해 `docs/PLANS.md`의 상태 관리와 커밋 전 확인을 돕습니다.
- 검증 중 발견한 문제는 `docs/PLANS.md`에 후속 작업으로 남깁니다.

## 작성 예정 항목

- 기능별 확인 항목
- 빌드 확인 항목 (플랫폼, 빌드 구성)
- 플레이 테스트 체크리스트 (게임 프로젝트)
- 시각 검증 (레퍼런스 이미지·스크린샷 비교, 아티팩트 확인)
- 그래픽스 디버깅 (API 검증 레이어 경고, RenderDoc 등 프레임 캡처)
- 성능 확인 (FPS, CPU/GPU 프레임 타임, 메모리, `docs/SPEC.md`의 성능 예산 대비)
- 회귀 확인 항목
- 알려진 문제
- 완료 기준
