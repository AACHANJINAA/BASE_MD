# Project Brief

이 문서는 프로젝트의 핵심 기획과 설계 방향을 정리하는 기준 문서입니다.

게임 프로젝트에서는 GDD(Game Design Document) 역할을, 그래픽스 프로젝트에서는 기술 목표와 범위를 정의하는 역할을 합니다. 해당하지 않는 항목은 비워 둡니다.

## 문서 역할

- 프로젝트 유형, 목표, 범위를 기록합니다.
- 핵심 기능과 결과물이 어떤 모습이어야 하는지 정리합니다.
- 구현 문서와 충돌할 경우, 의도와 설계 방향을 확인하는 원본 자료로 사용합니다.

## 작성 예정 항목

### 공통

- 프로젝트 개요 (유형: 게임 / 렌더러·엔진 / 셰이더·이펙트 / 데모 / 툴)
- 목표와 핵심 가치
- 범위와 비범위 (하지 않을 것)
- 대상 플랫폼, 엔진/프레임워크, 그래픽스 API
- 아트 스타일과 비주얼 레퍼런스
- 주요 기능 목록
- 사운드와 연출

### 게임 프로젝트

- 핵심 재미와 플레이 루프
- 조작 방식
- 캐릭터와 적
- 레벨과 스테이지
- UI/UX
- 밸런스 방향

### 그래픽스 프로젝트

- 구현할 기법과 참고 자료 (논문, 발표, 레퍼런스 구현)
- 결과물 형태 (실시간 데모, 라이브러리, 에디터 툴 등)
- 품질 목표와 성능 목표
- 사용자 조작과 파라미터 (카메라, 디버그 UI)
